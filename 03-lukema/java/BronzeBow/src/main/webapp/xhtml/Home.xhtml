Welcome to AskBuffett.com

This web site is intended to give you another view of stock moving trends. It is based on java JApplet. Your web browser needs to support java to be able to display the charts.

The charts here are good for middle term and long term investments. For example, investments that will be held for more than a week, 401K, IRA, and education fund management, etc. The charts are not recommended for day trading for lack of hourly data.

Clicking on the symbols on left navigation panel or input a stock ticker will lead you to the technical analysis charts.
