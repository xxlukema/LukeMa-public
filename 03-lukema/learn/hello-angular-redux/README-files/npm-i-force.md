# `npm i --force`

## Initial Install

1. [After Download nodejs.zip File From]<https://nodejs.org/en/download/>
2. Unzip the file, and add the dir to PATH
3. Run The Following Command In CMD Console under **ANY** direcory:

```cmd
npm install --force --location=global npm-check-updates
npm install --force --location=global ts-node
npm install --force --location=global python python2 python3
npm install --force --location=global @angular/cli @angular/core

npm i --force
npm install -g npm-check-updates
```
