# `ng g`

## Commands

    # generate form with routing
    ng g m form --routing

    # generate components inside "form" module
    ng g c form

    # generate service inside "form" module
    ng g s form/form

    ng g guard auth
    ng g d directive/change-bg-color
    ng g interface module-name/interface-name --type rest  
    ng g class utils/file-utils
