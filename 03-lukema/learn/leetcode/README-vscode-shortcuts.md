# vscode keyboad shortcuts

## Required

Install `Eclipse Keymap (by Alphabot)` Extension

## Select multiple line

### 1. `Shift + Alt + down arrow key` <=== Can only use `down arrow key`

### 2. `Shift + Alt + click/drag mouse left button` <=== Can block select up/down directions

## Move line up/down

    Alt + Up/Down Arrow
