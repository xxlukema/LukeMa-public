## How-to: Conditional Execution

Syntax

if `command1` succeeds then execute `command2` (IF)

    command1 && command2

Execute `command1` and then execute `command2` (AND)

    command1 & command2

Execute `command2` only if `command1` fails (OR)

    command1 || command2
