

Observer Pattern (Publish/Subscribe): To observe the state of an object.
It is related to the principle of implicit invocation.

This pattern is mainly used to implement a distributed event handling system. 

The primary objective of this pattern is to provide a way to handle 
runtime one-to-many relationships between objects in object oriented 
languages. The event from the observable object's point of view is called 
notification and the event from the observers' point of view is called update.


See java.util.Observable/java.util.Observer
