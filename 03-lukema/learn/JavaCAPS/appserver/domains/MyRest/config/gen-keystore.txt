

<c:\JavaCAPS>\appserver\domains\<MyDomain>\config\cacerts.jks

It is recommended to use the default KeyStore:

   <c:\JavaCAPS>\appserver\domains\<MyDomain>\config\keystore.jks

You must specify a fully qualified domain for the “first and last name” question. 
The reason for this use is that some CAs such as VeriSign expect this properties to 
be a fully qualified domain name.   

There are CAs that do not require the fully qualified domain, but it is recommended 
to use the fully qualified domain name for the sake of portability. All the other 
information given must be valid.


1. Create directory:

	mkdir -p JavaCAPS/appserver/domains/MyRest/config

2. Create ketstore:

	In the above directory:
	
	keytool -genkey -alias luke -keyalg RSA -keysize 2048 -keystore lukema-keystore.jks
	keystorepassword: lukema
	first and last name: localhost
	password: lukema
	CN: localhost

3. List

	keytool -list -v -keystore lukema-keystore.jks -storepass lukema

4. Create CSR file:

	keytool -keystore lukema-keystore.jks -certreq -alias luke -keyalg rsa -file lukema.csr
	
5. Certify

   

6. Download cer

7. Import

	keytool -import -alias luke -trustcacerts -file cert.p7b -keystore lukema-keystore.jks
	
8. Edit tomcat server.xml:

    <Connector SSLEnabled="true" 
	           clientAuth="false" 
	           keyAlias="luke" 
	           keystoreFile="C:/JavaCAPS/appserver/domains/eCertService/config/lukema-keystore.jks" 
			   keystorePass="lukema" 
			   maxThreads="150" 
			   port="8443" 
			   protocol="org.apache.coyote.http11.Http11Protocol" 
			   scheme="https" 
			   secure="true" 
			   sslProtocol="TLS"/>
	
8. Import CARoot.p7b to IE and Firefox	
	
	CARoot.p7b, lukema-IntermediateCA.p7b

9. Export public key

    keytool -export -keystore ddtrust.jks -alias mykey -file ddtrust.cer   <welcome1>
	
10. Import 
	
	keytool -import -alias ddtrust -trustcacerts -file ddtrust.cer -keystore lukema-keystore.jks
