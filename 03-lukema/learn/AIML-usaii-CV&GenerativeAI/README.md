# Concepts

## IoU - 

- IoU is calculated by dividing the area of overlap between two bounding boxes (the intersection) by the
  area of their union (the total area covered by both boxes).
- The result is a value between `0` and `1`, where `0` represents no overlap and `1` represents perfect overlap.
- It is a crucial metric in object detection because it directly reflects how well the model's predicted box aligns
  with the actual object's boundaries.
